SKILLVAULT STARTER WEBSITE
==========================

WHAT'S INCLUDED
- Responsive landing page for phones and computers
- Product cards with sample products and GHS prices
- Search and category filters
- Working demo cart (add/remove items and total)
- Free-resource sample card
- Mobile navigation
- No paid libraries or frameworks required

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Try the search, category buttons, and cart.

IMPORTANT BEFORE LAUNCH
This is a front-end starter/demo, not a live store yet.
- The sample product names, descriptions, and prices are placeholders.
- No actual downloadable product files are included.
- Checkout/payment is NOT connected.
- The cart is stored only while the page is open.
- Do not advertise "secure payment" or "instant download" as working until those systems are implemented.
- Add your real contact email and social accounts.
- Create original product files and test them.
- To accept payments, choose a supported provider, complete its account setup, and integrate it securely. Never put secret API keys in front-end JavaScript.

FREE HOSTING OPTIONS
- GitHub Pages: https://pages.github.com/
- Netlify: https://www.netlify.com/
Static hosting can publish the front end for free on eligible plans. A custom domain, payment provider, or other services may cost money.
